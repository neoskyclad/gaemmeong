# Project guidance

- Before planning or implementing a feature, review the relevant documents under `Docs/` for established technical decisions.
- Treat documented decisions as the project baseline. If the user's current instruction changes a decision, follow the current instruction and update the relevant document.
- When a meaningful technical decision is made or changed, record the conclusion and rationale under `Docs/`.
- Keep project documents concise and distinguish confirmed decisions, tentative choices, and open questions.
