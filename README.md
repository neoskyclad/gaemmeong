# GaemMeong (겜멍)

가만히 두어도 세계와 구성원들이 스스로 살아가는 원시 부족 시뮬레이션 게임입니다.

현재는 절차적 월드 생성기를 만드는 초기 프로토타입 단계입니다.

## Development environment

- Unity `6000.3.22f1` (Unity 6.3 LTS)
- Universal Render Pipeline 17.3
- Windows

## Repository layout

Unity가 생성하는 캐시와 로컬 사용자 설정은 버전 관리에서 제외합니다. 프로젝트를 여는 데 필요한 `Assets`, `Packages`, `ProjectSettings`만 Git으로 추적합니다.
