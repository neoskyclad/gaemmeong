# 3단계: 시드와 기본 지형 생성

## 확정 내용

- 월드 시드 텍스트는 0 이상의 정수 문자열이면 그 숫자를 그대로 `ulong` 시드로 사용하고, 그 외 문자열은 공백을 제거한 뒤 UTF-8 FNV-1a 64비트 해시로 변환한다.
- 생성 요소별 하위 시드는 `SplitMix64`로 분리한다. 지형, 산악 마스크, 대륙 마스크, 해안선, 물, 식생, 동물이 서로 난수열을 공유하지 않도록 도메인을 구분한다.
- 노이즈는 시드 기반 2D Gradient Noise를 여러 옥타브로 합성한 fBm으로 만든다. 월드 절대 좌표를 샘플링하므로 청크 경계에서 같은 좌표는 같은 값을 얻는다.
- 기본 지형은 `BaseWavelength=192`, `Octaves=4`, `Lacunarity=2`, `Persistence=0.5`로 시작한다. 생성 결과를 본 뒤 조정할 수 있는 내부 초기값이다.
- 1차 고도 범위는 `-16..+48`, 해수면은 `0`이다. 이 단계에서는 기본 지형 노이즈를 고도 배열과 디버그 배열에 기록한다.

## 구현 및 검증

- 동일한 시드와 설정은 동일한 고도 배열 및 체크섬을 생성한다.
- 시드 입력은 숫자/문자열 모두 가능하며, 빈 값은 설정 검증에서 거부한다.
- Unity Edit Mode 테스트 34개 통과, 컴파일 성공.
