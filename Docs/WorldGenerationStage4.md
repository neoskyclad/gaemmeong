# 4단계: 지형·육지 마스크와 바다 판정

## 확정된 구조

- 대륙 형태는 독립된 시드 도메인의 저주파 fBm, 해안선 fBm, 맵 가장자리로부터의 거리 마스크를 합성한다.
- 군도/대륙/판게아의 임계값은 생성기 내부 초기값이며, 사용자는 프리셋만 고른다. 실제 결과를 화면으로 확인한 뒤 형태와 비율을 조정한다.
- 평지/균형/산악은 산악 마스크와 고도 범위를 다르게 만든다. 고도는 해수면 아래 `-16..-1`, 육지는 `+1..+48` 범위다.
- 맵 가장자리의 바다 후보에서 4방향 flood fill을 실행해 외해와 연결된 타일만 `Ocean`으로 표시한다. 외해와 연결되지 않은 저지대는 현재 `Dry`로 남겨 둔다. 저지대를 호수/내해로 구분하는 것은 별도 수계 설계 항목이다.
- 높이 경사는 상하좌우 이웃과의 최대 고도차로 정규화해 디버그 배열에 저장한다.

## 검증 결과

- 3개 지형 프리셋 × 3개 대륙 프리셋 모두 유효한 고도/마스크를 생성한다.
- 동일 설정의 결과가 재현되고, 판게아가 군도보다 많은 육지를 생성한다.
- Unity Edit Mode 테스트 45개 통과.

## 조정 대기

- 프리셋별 육지 면적, 해안선 굴곡, 산악 밀도는 프로토타입을 직접 확인하고 조정한다. 현재 수치는 디자인 확정값이 아니라 첫 화면을 만들기 위한 초기 파라미터다.
